Proyectos Destacados
ESCALADA — Gestión de Competiciones
Laravel PHP MySQL

Aplicación web completa para la gestión de competiciones de escalada deportiva en Andalucía. Implementa un sistema de roles diferenciados (administrador, árbitro, entrenador y competidor), inscripciones con validación documental adjunta, gestión de copas por temporada y clasificaciones automáticas. Desarrollada con el framework Laravel siguiendo arquitectura MVC, base de datos relacional MySQL y desplegada en servidor propio sobre Raspberry Pi.

ZIRPO — App de Carpooling
React Express MariaDB

Plataforma de movilidad compartida para publicar y unirse a viajes en coche, con cálculo y reparto de gastos entre ocupantes. Integra la API de Google Maps para selección de rutas, paradas intermedias configurables y precios por tramo. Arquitectura full-stack: frontend en React, API REST con Node.js y Express, base de datos MariaDB. Desplegada en Raspberry Pi con dominio propio.

POKER SENCILLO — Juego de Poker Online
PHP HTML CSS

Juego de poker funcional desarrollado íntegramente en PHP orientado a objetos. Implementa la lógica completa del juego: generación y barajado de baraja, reparto de cartas, detección y evaluación de manos, gestión del estado de la partida y ciclo de juego entre varios jugadores. Desplegado sobre servidor Apache en Raspberry Pi con acceso desde internet.

CUENTA ATRÁS — Countdown en Tiempo Real
HTML CSS JS

Aplicación web de contador regresivo en tiempo real con soporte de múltiples zonas horarias (zona horaria de Salt Lake City, Utah). Muestra el tiempo restante desglosado en meses, días, horas, minutos y segundos, actualizándose cada segundo mediante JavaScript puro sin dependencias. Demuestra manejo de la API de fechas de JS y manipulación dinámica del DOM.
